Introduction

Standard Classical Computing models use binary bits of either value 0 or 1 (either on or off) whilst in small numbers of binary bits cannot display a lot of information eg 4 bits can represent 16 different pieces of information the formula for this is N=2^n. Classical computers are simply systems of Billions of these bits set up to create logic gates which can be used to perform calculations. This Binary system powers almost all software in today’s world. While Quantum computers use Qubits which differ from Binary bits in the sense that instead of only being on or off, Qubits can be in a superposition of either “on or off” until observed.
